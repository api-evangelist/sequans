# Sequans

> Sequans Communications S.A. (NYSE: SQNS) is a Paris-based fabless semiconductor company designing 5G and 4G cellular IoT chips and modules (Monarch LTE-M/NB-IoT, Calliope Cat 1bis, Cassiopeia Cat 4/Cat 6, Taurus 5G) plus the Iris SDR transceiver and licensable IP. Sequans sells hardware to device makers and publishes no developer API for its products; the only machine-readable surface on sequans.com is an OAuth-gated Model Context Protocol server run by the WordPress MCP Adapter on its corporate website.

This file was generated by API Evangelist from the live Sequans public surface on 2026-09-16.
Sequans does not publish an llms.txt of its own (https://sequans.com/llms.txt returns 404).
Nothing below is documented by Sequans as an API; every endpoint was probed directly.

## APIs

- [Sequans Website MCP Server](https://sequans.com/wp-json/mcp/mcp-oauth-server): Remote MCP server (WordPress MCP Adapter). OAuth 2.1 authorization code + PKCE, single `mcp` scope. Anonymous tools/list returns 401, so the tool list is not public. It fronts the corporate website, not chip or module products.

## Authentication

- [OAuth authorization server metadata (RFC 8414)](https://sequans.com/.well-known/oauth-authorization-server): issuer https://sequans.com; authorize, token and revoke endpoints under https://sequans.com/oauth/.
- [OAuth protected resource metadata (RFC 9728)](https://sequans.com/.well-known/oauth-protected-resource): names the MCP server as the protected resource.
